# Ironbook

Personal workout tracker. Live app: https://tweilun511-cyber.github.io/ironbook/

- `index.html` — the built app (single file, served by GitHub Pages)
- `source/` — React + TypeScript + Tailwind source. `cd source && npm install && npm run build`, then copy `source/dist/index.html` to the repo root.

Workout data is stored only in the browser on your device. Use Settings → Export backup regularly.
